# IPA Ink

British IPA handwriting practice for touchscreens, tablets and desktop browsers.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public Pages address when deployment finishes.

## Local use

Open `index.html` directly in a modern browser. Drawing progress is stored only in that browser's local storage.

## Contents

- `index.html` — complete self-contained application
- `.nojekyll` — tells GitHub Pages to serve the files without Jekyll processing
